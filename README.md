# Stallora AI

**Predictive Parking Intelligence**

Stallora AI is an interactive graduate project exploring how parking-demand forecasting can support better campus arrival decisions. The current pilot focuses on Wayne State University Parking Structure 2 and the recurring weekday congestion period reported around Anthony Wayne Drive and Warren Avenue.

## Pilot focus

- Location: Parking Structure 2 (Manoogian Structure)
- Primary user: Student or campus commuter
- Recurring congestion: Monday–Thursday, 3:00–5:30 PM
- Goal: Help users plan arrival times before entering a congested campus corridor

## Prototype features

- Hourly occupancy forecast
- Expected availability and search time
- Interactive arrival planner
- Peak-period recommendations
- Demonstration email and mobile verification flow
- QR poster for mobile access
- Responsive desktop and mobile design

## Data statement

Displayed occupancy values are synthetic demonstration data. The operating context and congestion window are grounded in stakeholder correspondence with Wayne State University Parking & Transportation Services dated May 27, 2026. The prototype is not connected to live university systems.

## Technology

- Next.js
- React
- TypeScript
- Tailwind CSS
